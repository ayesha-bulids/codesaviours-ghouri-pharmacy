## How to Run Locally

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open `index.html` in your browser.

## How to Update Medicines

1. Open `js/products.js`.
2. Update medicine names, prices, descriptions and images.
3. Save the file.
4. Push changes to GitHub.
5. Netlify will automatically deploy the updates.

## Deployment

The website is hosted on Netlify and connected to the GitHub repository.
